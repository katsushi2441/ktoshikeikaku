住所を入れると、**その場所の都市計画**を一度に返すシステムです。

土地の相談を受けるたびに、市区町村の都市計画図を開いて拡大し、境目を探して、用途地域の凡例と建ぺい率・容積率を読み取る。市街化調整区域かどうか、防火地域か、都市計画道路がかかっていないかは、また別の図で確かめる。この下調べを、住所ひとつで済ませます。

■ 返ってくるもの

1. **用途地域** … 名称と、その場所の建ぺい率・容積率
2. **区域区分** … 市街化区域／市街化調整区域／区域区分のない都市計画区域
3. **防火地域・準防火地域、高度地区・高度利用地区、特別用途地区、地区計画、風致地区**
4. **立地適正化計画** … 居住誘導区域・都市機能誘導区域
5. **都市計画道路** … 約20m以内にあるか、何mか

結論は判定結果から規則で作ります（例: 市街化調整区域なら「開発や建築には原則として許可が要る（都市計画法第29条・第34条）」）。

■ 収録

- 全国47都道府県・1,377市区町村・約41.8万区域（国土交通省 都市計画決定GISデータ 令和7年度版）
- 都市計画法・建築基準法・都市再生特別措置法の条文42か所と、建築基準法 別表第二（用途地域ごとに建てられる／建ててはならない建物）
- 用語・用途地域13種・調べ方の解説ページ34本、都道府県47・市区町村1,377の内訳ページ

**都市計画は都道府県ごとに1ファイル**です。要る県だけ置けば動きます。置いていない県は「未収録」と返し、「区域外」とは書きません。

■ AIチャットとMCP

- **AIチャット** … 「この土地に3階建ては建てられる？」のような質問に、判定結果と条文だけを材料に答えます。AIは言い換えるだけで、データに無い数字や条例の中身は作りません。社内の Ollama など OpenAI 互換の窓口を1行書けば使えます。書かなければ、判定結果だけを返します
- **MCP** … Claude Code・Claude Desktop・Codex などのAIエージェントから、住所の都市計画・用語と条文・市区町村の内訳を直接引けます（`/mcp`、Streamable HTTP）
- **JSON API** … `/api?q=住所`

■ しないこと

- **建てられる・建てられないを断定しません。** 調べる前の下ごしらえです
- **条文を要約・言い換えしません。** 引用は e-Gov 法令APIの本文のまま
- 角地の建ぺい率緩和、前面道路の幅による容積率の制限、条例の上乗せは判定に含みません

出典の国土交通省は「建築確認申請や不動産重要事項説明等の手続に用いることを保証するものではなく、参考情報として利用を想定」としています。画面にもそのまま出しています。最後は市区町村の都市計画課・建築指導課で確かめる前提の作りです。

■ 置き方

1. ktoshikeikaku.php と ktoshikeikaku_data/ を置く
2. その階層の .htaccess に AddHandler php-script .php を書く（heteml の場合）
3. 設定ファイルの見本をコピーして、必要ならAIの窓口を書く
4. ブラウザで開く

PHP 8 と PDO SQLite だけで動きます。データベースサーバーも常駐プロセスもポートも要りません。用語・都道府県・市区町村のページとサイトマップ・構造化データ（FAQ・パンくず）・llms.txt も自動で出るので、自社サイトの集客ページとしても使えます。

■ データを新しくする

国土交通省の新しい年度のデータが出たら、同梱のPythonで作り直せます。

```
python3 scripts/build_db.py
python3 scripts/national_stats.py
python3 scripts/extract_law.py
python3 scripts/terms.py
```

■ こんな方に

- 不動産会社 … 物件の問い合わせや査定の前に、用途地域と市街化調整区域を先に押さえたい
- 設計事務所・工務店 … 最初の打ち合わせで、建ぺい率・容積率と防火地域をその場で見たい
- 自社サイトの集客 … 「〇〇市 用途地域」「建ぺい率とは」で検索する人の受け皿を置きたい
